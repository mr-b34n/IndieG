# PRODUCT MEMORY

## Decision: Hybrid Social + Forum

Status: Active

Date: 2026-08-30

Decision:

The product is a hybrid social + forum/community platform.

Why:

The product combines social discovery with deeper community discussions.

Implications:

New features should consider relationships between users, communities, content, and games rather than treating each domain as isolated.

---

## Decision: Content and Community First

Status: Active

Date: 2026-08-30

Decision:

Content discovery and community participation should take priority over decorative UI.

Why:

The product's primary value comes from content and community interaction.

Implications:

When there is a conflict between decorative complexity and useful content hierarchy, prefer the latter.

---

## Decision: Search as Discovery

Status: Active

Date: 2026-08-30

Decision:

The main search surface is primarily for discovery, not complete result listing.

Why:

Search can produce many results across multiple entity types.

Implications:

Use concise previews and progressive discovery for large result sets.
