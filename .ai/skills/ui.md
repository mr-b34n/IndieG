# UI SKILL

Use this skill for frontend/UI/UX work.

## Workflow

1. Inspect existing page/component.
2. Find similar existing UI.
3. Reuse existing components and design tokens.
4. Identify affected states.
5. Implement the smallest consistent change.
6. Verify responsive behavior when relevant.

## Design Priorities

Prefer:

1. hierarchy
2. spacing
3. typography
4. surface contrast
5. subtle elevation
6. restrained accents

Avoid using borders, cards, colors, or gradients merely as decoration.

## Required States

When relevant, consider:

* loading
* empty
* populated
* error
* disabled
* unauthorized
* unverified
* mobile

## Consistency

A new component should look like it belongs to the existing application.

Do not introduce a new visual language for an isolated page.
